# Upstream provenance

Paginotto firmware starts from the Pala One firmware project:

- Upstream repository: https://github.com/PaulLagier/pala-one-firmware
- Upstream author: Paul Lagier
- Imported branch: `main`
- Imported commit: `2c82e59e0f6e87afd204606b930f15cf7b5b7b8a`

This repository is a substantially modified derivative for the Paginotto
e-reader. Paginotto-specific product code, firmware behaviour, device/WebUI
design and deployment work are maintained separately in this repository.

The upstream repository does not provide a standard LICENSE file. This is why
Paginotto does not claim a new MIT/GPL/Apache license over the complete
derivative: doing so would incorrectly relicense inherited upstream code.

The `upstream` Git remote points to the original repository. Product branding,
feature selection, and future changes are maintained in this repository.
